**GameSphere - Ультимативная Коллекция Настольных Игр**
Club "Cube" - это веб-платформа, представляющая собой интерактивный каталог настольных игр с детальными описаниями, правилами и возможностью просмотра видеообзоров. Проект создан с использованием современных веб-технологий и фокусируется на пользовательском опыте и адаптивном дизайне.

Особенности
🎲 Более 18 настольных игр с подробными описаниями
📱 Полностью адаптивный дизайн для мобильных устройств
🎨 Современный визуальный дизайн с анимациями и переходами
🔍 Поиск и фильтрация по категориям
📹 Интеграция с YouTube для видеообзоров
🌙 Темная тема с градиентами и эффектами

Технологии:
- HTML5
- CSS3 (с анимациями и адаптивностью)
- JavaScript (без внешних библиотек)
- Адаптивный дизайн (mobile-first подход)

Функциональность:
- Просмотр списка настольных игр
- Детализированные карточки с описанием и правилами
- Модальные окна с дополнительной информацией
- Поиск по названию и категории
- Фильтрация по типу игры
- Анимации при наведении и прокрутке
- Кнопка просмотра видеообзоров на YouTube
